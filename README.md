## Selected work

### [English Academy — Operations Platform](https://github.com/mrtolg7/english-academy-admin-panel-showcase)

Production-tested management software for student records, class groups, attendance and tuition collection. Built with React, Express 5, PostgreSQL and Railway, with separate financial authentication, XLSX reporting and transactional backup/restore.

### [Samsun Municipality — AI Information Assistant](https://github.com/mrtolg7/samsun-municipality-ai-assistant-showcase)

Independent end-to-end RAG assistant using a .NET ingestion worker, local bge-m3 embeddings, Qdrant retrieval, multi-provider LLM fallback and streamed React responses.

### [Samsun Districts Explorer](https://github.com/mrtolg7/samsun-districts-explorer-showcase)

Scraper-driven civic data platform covering 17 districts and 1,267 neighbourhoods with ASP.NET Core, Playwright, SQLite and React.
